# ResourceRace

[English](README.md) | 日本語 | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

資源ワールドをリセットした直後から、そのワールドで指定アイテムを集めた順に順位を決め、スパコインを渡すPaperプラグインです。

- 同時に走るレースは1本だけです。新しいレースを始めると、進行中のレースは先に終了します。
- お題は、ワールドごとに設定した候補から1つ抽選します。
- 報酬は順位ごとにVault経由で1回だけ払います。支払い済みを保存するので、再起動しても同じ人に二度払いません。
- 順位はチャットで全体に知らせ、本人にはタイトルも出します。
- レース中、対象ワールドの中で手に入れたアイテムだけに印を付け、それを数えます。
- 開始と終了はコンソールとRCONからだけです。プレイヤーは`/race`で状況を見られます。

## 動作環境

- Paper 1.21.4以降（Paper 26.2で動作確認）
- Java 21以降（サーバーのバージョンが要求するもの）
- [Vault](https://www.spigotmc.org/resources/vault.34315/)と経済プラグイン（EssentialsXを想定）

## 導入手順

1. [Releases](https://github.com/spa77k/ResourceRace/releases)から`resourcerace-1.0.0.jar`をダウンロードします。
2. Vaultと同じ`plugins/`フォルダーに置きます。
3. サーバーを再起動します。`plugins/ResourceRace/config.yml`ができます。
4. 資源ワールドを`worlds`に書き、サーバーを再起動します。
5. リセットのあと、コンソールかRCONから`race start <ワールド>`を実行します。

## コマンド

| コマンド | 使える人 | 内容 |
| --- | --- | --- |
| `/race` | 全員 | お題、対象ワールド、期限、自分の進み具合、順位一覧を表示する |
| `/race start <ワールド>` | `resourcerace.admin` | レースを始める。進行中のレースがあれば先に終了する |
| `/race stop` | `resourcerace.admin` | 進行中のレースを終了する |
| `/race reload` | `resourcerace.admin` | `config.yml`を読み込み直す |

`resourcerace.admin`の既定はopです。コマンドはコンソールとRCONから使え、対象ワールドはまだ読み込まれていなくてもかまいません。

### 返す結果

| 結果 | 意味 |
| --- | --- |
| `RESOURCE_RACE_OK started world=<ワールド> item=<MATERIAL> amount=<件数> race=<race-id>` | レースを開始した |
| `RESOURCE_RACE_ERROR world-not-configured` | `worlds`に無いワールド |
| `RESOURCE_RACE_ERROR no-targets` | そのワールドの候補がすべて不正だった |
| `RESOURCE_RACE_OK stopped` | レースを終了した |
| `RESOURCE_RACE_ERROR no-race` | 終了するレースが無かった |
| `RESOURCE_RACE_OK reloaded` | `config.yml`を読み込み直した |

## 設定

`plugins/ResourceRace/config.yml`

| キー | 既定値 | 内容 |
| --- | --- | --- |
| `worlds` | 資源ワールド3つ | レースできるワールド。ワールドごとに`display-name`と`targets`を持ちます。 |
| `worlds.<ワールド>.targets[].item` | | 候補のMaterial名。 |
| `worlds.<ワールド>.targets[].amount` | | 集める個数。 |
| `rewards` | `[1000, 500, 300]` | 順位ごとのスパコイン。要素数が順位の数になります。 |
| `duration-hours` | `167` | レースの長さ（時間）。次のリセットと重ならないよう、7日より少し短くします。 |

レースを始めると、そのワールドの`targets`から1つ抽選します。知らないMaterial名や`amount`が1未満の候補は、読み込み時に警告して除外します。

レースと順位は`plugins/ResourceRace/state.yml`に残します。

## 印の付き方

レース中、対象ワールドの中でアイテムを手に入れたときに印を付けます。数えるのは、お題のMaterialで、今のレースの、自分の印が付いたアイテムだけです。持ち物（ストレージ）とオフハンドを数え、エンダーチェストは数えません。

数えられるもの:

- 自分で壊したブロックのドロップ（コンテナと、自分で置いたブロックは除く）。
- モブなどプレイヤー以外のエンティティのドロップ。
- チェストなどの戦利品。
- 釣りで釣れたアイテム。
- ピグリンの物々交換の結果。
- 自然生成の額縁から取り出した・壊して落ちたアイテム。
- 印の付いた材料をかまどで焼いた結果。
- 空でない材料がすべて同じ持ち主の印付きだったときの、作業台の結果。

かまどと作業台は、材料の印を引き継ぐだけなので、対象ワールドの外で使っても結果に印が付きます。順位の判定は、どのワールドにいても行います。

数えられないもの:

- 対象ワールドの外で手に入れたもの。
- 自分で置いたブロックのドロップ。
- 壊したコンテナのドロップ。
- 何かのアイテムを拾っていたモブのドロップ。
- 自分で置いた・中身を入れた額縁のアイテム。
- 印の無いもの、他人の印のもの、古いレースの印のもの。
- エンダーチェストの中のもの。

古いレースの印は、ログイン時、インベントリを開いたとき、レース終了時に消します。レースのあとに普通のアイテムとスタックできなくなる状態を残しません。
